# Лабораторная работа №3. Использование глубоких нейронных сетей при обработке изображений

**Вариант 3:** EuroSAT — классификация спутниковых снимков (10 классов, 64x64 RGB).  

**ФИО:** Горюнова Алина

**Номер зачётной книжки:** ИЦ-230453

## Цель работы
Получить практический опыт проектирования, обучения и анализа свёрточных нейронных сетей (CNN) для задачи классификации изображений на PyTorch (CPU): освоить загрузку данных через torchvision и аугментации, обучить оригинальную CNN с нуля, применить transfer learning на предобученном backbone (`timm`), оценить качество метриками классификации и матрицей ошибок, провести анализ ошибок и интерпретацию модели (Grad-CAM, фильтры), а также сохранить веса модели и оформить воспроизводимый проект.

## Датасет
EuroSAT, загружается строго через `torchvision.datasets.EuroSAT(root="./data", download=True)`.  
Датасет содержит 27 000 спутниковых снимков размером 64x64 RGB.  
Согласно методическим указаниям, данные разделены на train/val/test (15% val, 15% test) с фиксированным seed. Для обеспечения local-first запуска на CPU к обучающей выборке применена подвыборка (`torch.utils.data.Subset`) до 4000 изображений. Файлы данных в репозиторий не коммитятся (папка `data/` добавлена в `.gitignore`).
