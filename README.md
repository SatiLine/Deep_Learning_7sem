Репозиторий содержит лабораторные работы по дисциплине «Глубокое обучение и анализ данных». Каждая работа лежит в своей папке и состоит из Jupyter Notebook с кодом, графиками и выводами, файла `requirements.txt` с зафиксированными версиями пакетов и собственного `README.md` с описанием и командой запуска.

## Окружение
* Python 3.12
* Зависимости каждой работы зафиксированы в её `requirements.txt` 
* Для запуска ноутбуков дополнительно нужен JupyterLab (на результаты не влияет)

## Запуск любой работы
```bash
git clone <ссылка на репозиторий>
cd <папка репозитория>/labN             # например, lab1

python3.12 -m venv .venv
source .venv/bin/activate              # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pip install jupyterlab

jupyter lab                            # открыть ноутбук и выполнить все ячейки (Run All)
```

## Воспроизводимость
* В начале каждого ноутбука задан номер варианта и seed (`VARIANT = 3`, `SEED = VARIANT`), `random_state` передаётся в разбиение данных, модели, кросс-валидацию и подбор гиперпараметров.
* Версии пакетов зафиксированы в `requirements.txt`.
* Предобработка оформлена как sklearn-пайплайн: `fit` выполняется только на обучающей выборке.

## Данные
Файлы данных в репозиторий не коммитятся (папки `data/` указаны в `.gitignore`). Каждый ноутбук скачивает свой датасет автоматически один раз; источник и лицензия указаны в `README.md` соответствующей работы. Если автоматическая загрузка не сработала, скачайте данные по ссылке из README работы и положите файлы в папку `labN/data/`.
