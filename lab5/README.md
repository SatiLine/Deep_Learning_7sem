## Цель работы
Получить практический опыт полного цикла работы с векторными представлениями на PyTorch (CPU): обучить контрастивный энкодер без ручной разметки (self-supervised), заморозить его и извлечь L2-нормализованные эмбеддинги, построить обязательный линейный базлайн PCA/SVD, честно сравнить представления протоколами linear probe и kNN-пробы, собрать локальный векторный индекс USearch и измерить `ann_recall@k` относительно точного поиска, а также оформить воспроизводимый проект (seed, requirements.txt, README).

## Датасет
Публичный датасет **CIFAR-10** (загружается автоматически через `torchvision.datasets.CIFAR10`).
- **Обучающая часть:** 50 000 изображений. Для обучения энкодера без меток используется фиксированная подвыборка `enc_pool` размером 5 000 изображений (согласно требованиям Варианта 3).
- **Сплит для оценки (probe):** 10 000 изображений с метками (train) и 10 000 изображений (test).
- Разделение на сплиты выполнено строго до вычисления любых статистик (PCA, Scaler) для предотвращения утечки данных (data leakage). Файлы данных в репозиторий не коммитятся (папка `data/` добавлена в `.gitignore`).
