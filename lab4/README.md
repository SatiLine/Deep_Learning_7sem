## Цель работы
Получить практический опыт анализа временных рядов: подготовить ряд и скользящее окно, выполнить разделение по времени без утечки, построить и сравнить статистические базлайны (наивный, сезонный наивный, ETS, ARIMA) и градиентный бустинг с рекуррентными нейронными сетями (LSTM, GRU) на PyTorch (CPU), оценить качество метриками MAE, RMSE, MASE и квантильной (pinball) потерей, провести walk-forward backtesting и анализ ошибок по горизонту, а также оформить воспроизводимый проект.

## Датасет
Учебный временной ряд, сгенерированный в соответствии с протоколом Варианта 3. Исходный ряд (156 недель) приведён к регулярной минутной сетке с помощью линейной интерполяции, пропуски обработаны без заглядывания в будущее, выполнена стационаризация (дифференцирование порядка 4). 
Для обеспечения стабильного обучения на CPU и соблюдения протокола курсовой работы (окно 1440 шагов, горизонт 2880 шагов) используется рабочий фрагмент ряда длиной 25 суток (36 000 минут), что достаточно для формирования хронологических сплитов train/val/test с необходимыми зазорами. Файлы данных в репозиторий не коммитятся (папка `data/` добавлена в `.gitignore`).
